# Data Model: Feature 007

## QueryRewrite

Original query, bounded alternatives, detected language, alias/version terms, and rewrite version.

## RetrievalFilters

Provider/framework, date range, version, language, and source-type constraints.

## RankedEvidence

Evidence ID, base/fused/rerank scores, authority, freshness, diversity key, original language and
parent source ID.

## RerankerDecision

Baseline/candidate metric maps, latency/cost deltas, dataset version and enablement decision.

## RetrievalEvaluation

Case ID, expected evidence IDs, returned IDs, Hit@5, MRR, context precision/recall, citation
precision, freshness accuracy, latency, cost and pass/fail status.
