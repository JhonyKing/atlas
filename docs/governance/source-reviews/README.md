# Official-source connector reviews

Each connector remains disabled unless its review file has `status: approved` and a reviewer has
verified all of the following against the live publisher pages: terms, robots instructions,
licensing basis, allowed hosts and paths, attribution requirements, and a re-review trigger.

The review date is not a permanent legal clearance. A terms, robots, license, documentation-host,
or publisher-policy change invalidates the approval and requires a new review before the connector
can be enabled. These reviews cover public documentation/release metadata only; they do not grant
access to private accounts, LangSmith workspaces, OpenAI API data, or third-party services.
