# Feature 003 report artifacts

These files are generated by the integration visual-QA test:

```powershell
cd apps/backend
.\.venv\Scripts\python.exe -m pytest tests/integration/reports/test_artifact_visual_qa.py -q
```

The test validates the report first, then saves the final DOCX/PDF bytes and a SHA-256 manifest.
The files are reproducibility evidence for the reports MVP, not source templates.
